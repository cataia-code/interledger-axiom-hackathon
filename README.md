# interledger-axiom-hackathon

Monorepo de AxiomOpenPayments.

- `api/`: API REST en Node.js (ver `api/README.md`).
- `payments/`: cliente de prueba de Open Payments contra la wallet de Interledger (ver `payments/README.md`). El contrato con el checkout está en `payments/INTEGRACION.md`.
- `AI_USAGE.md`: divulgación de uso de IA pedida por la hackathon.
